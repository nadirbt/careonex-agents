## How to run locally (no Docker needed)

```bash
aws sso login --profile careonex-team
export AWS_PROFILE=careonex-team AWS_REGION=us-east-1 AWS_DEFAULT_REGION=us-east-1

# terminal 1: retrieval API on :8080 (KB id is read from the bucket's config/knowledge-base.json)
uv run --directory services/retrieve careonex-retrieve serve

# terminal 2: mic-free voice round trip that must use the tool
CAREONEX_RETRIEVE_URL=http://127.0.0.1:8080 \
  uv run --directory services/voice careonex-voice-smoke --expect-tool lookup_program_info \
  --data-dir /tmp/voice-smoke
```

Use `--data-dir` outside the repo: the default `services/voice/data/` is not git-ignored.

## Changes in this branch (services/voice)

1. **Smoke test `--expect-tool NAME`.** Fails unless one call to NAME happened, succeeded (for
   `lookup_program_info`: no error and at least one passage), and its result was sent back on the stream.
   Without the flag the test still passes on any reply audio. Before this, the test passed with 0 tool calls.
2. **Tool outputs keyed by `toolUseId`.** Replaced `tool_calls[-1]`, which could store an output on the wrong
   call when tools overlap. Records now carry `result_sent`, `requested_at`, `result_sent_at`.
3. **Prompt.** Program facts only from `lookup_program_info`, even a short "yes". Look up first, then ask
   the one missing fact (resolves the old "ask age first" conflict). 2–3 sentences, about 40–60 words, one
   follow-up question, no lists. Keep each rule with its own program. No unstated comparisons. No promised
   follow-up unless `save_intake` succeeds. These are prompt targets, not guarantees.
4. **Passages cleaned before Sonic sees them** (`speakable_passage`). Markdown removed; tables become one
   line per row (cells labelled only when every column has a header); footnote marks kept; numbers kept.
   The old 1,200-char cut is replaced by the chunker's 2,800-char cap with an explicit "passage continues"
   marker.
5. **County validation** (`normalize_county`). Only the 21 NJ counties shape the query; "New Jersey", towns
   etc. are dropped (nothing substituted) and Sonic is told why.
6. **Tool guidance** repeats the length/format target and says to look up each program separately when
   comparing. Both were needed in live tests (see below).

Tests: `uv run --directory services/voice pytest -q` → 34 passed (7 new for tool results, 6 for formatting
and county).
